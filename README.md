## 📌 Project Overview

The Learning Management System (LMS) Dashboard is a business intelligence reporting project focused on monitoring academic activities and analyzing learning performance.

It uses Power BI, Power Query, and DAX to transform data from multiple Excel sheets into structured reports and interactive visualizations.

## 🎯 Project Objectives

- Monitor student attendance and classroom activities.
- Analyze conducted and missed classes.
- Track lesson-wise learning progress.
- Evaluate teacher-wise performance.
- Present key performance indicators through interactive reports.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Power BI Desktop | Dashboard development |
| Power Query | Data cleaning and transformation |
| DAX | Measures and calculations |
| Microsoft Excel | Data source |
| Google Sheets | Data handling |

## ⚙️ Project Workflow

1. **Data Loading:** Imported data from multiple Excel sheets.
2. **Data Transformation:** Cleaned and transformed data using Power Query.
3. **Data Preparation:** Used Append Queries to combine datasets and resolve column and data-type inconsistencies.
4. **Data Modeling:** Organized structured data for reporting.
5. **DAX Calculations:** Created measures to analyze class activities and performance.
6. **Visualization:** Designed interactive charts, KPI cards, tables, and slicers.

## 📈 Dashboard Features

### Key Performance Indicators
- Total Classes
- Conducted Classes
- Missed Classes
- Student Leaves

### Performance Analysis
- Student-wise attendance analysis.
- Teacher-wise class performance.
- Lesson-wise progress tracking.
- Class status distribution.
- Student–teacher class distribution.

### Interactive Features
- Student filter
- Teacher filter
- Date-range filter
- Interactive charts and tables

## 🧮 DAX Functions Used

- `CALCULATE()`
- `COUNT()`
- `DISTINCTCOUNT()`
- `IF()`
- `ISBLANK()`
- `VAR`
